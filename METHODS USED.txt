List of OCR Models We Tried:
Tesseract OCR

Open-source OCR engine.
Works offline.
Requires installation and proper path configuration.
Microsoft TrOCR (Base and Large Models)

Transformer-based OCR model fine-tuned for handwritten text.
Requires GPU for better performance.
Can struggle with different handwriting styles without fine-tuning.
PaddleOCR

Lightweight and efficient OCR solution supporting multiple languages.
Good accuracy and fast processing.
Works with printed and handwritten text.
EasyOCR

Deep learning-based OCR for multiple languages.
Simple and fast with good accuracy for handwritten text.
Easy to set up and run.
Google Cloud Vision API

Cloud-based OCR with high accuracy.
Offers free tier but requires API key.
Works well with printed and handwritten text.
Microsoft Azure Computer Vision API

Cloud-based OCR service with free tier.
High accuracy and supports handwritten text.
Requires an API key for access.
OCR.Space API

Free online OCR API with limited usage.
Good for quick tests but may struggle with handwriting.
No need for installation.
